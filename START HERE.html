OHS Store — Start Here

Everything you need to run the Ottawa High School Store website, in plain English.

This folder is the whole OHS Store website: the shop where students order Cyclones gear, and a private dashboard where Mr. Setzer manages orders, prices, designs and the Christmas collection. Nothing else needs to be bought.

Part 1 — Try it on your computer

Follow these steps one at a time. You only do steps 1, 2 and 4 once.

  1. Install Node.js (free, one time only) Go to nodejs.org and click the big green button that says LTS. Open the file that downloads and keep clicking Next until it says it's finished.
    Node.js is the free program that runs the store. You'll never need to open it yourself.
  2. Unzip this folder On Windows: right-click the zip file and choose Extract All, then Extract. On a Mac: just double-click the zip file. Put the folder somewhere easy to find, like your Desktop.
  3. Start the store Open the folder and double-click:

    🪟 Windows: Start OHS Store
    🍎 Mac: right-click Start OHS Store (Mac), choose Open, then Open again. (Mac only asks this the first time.)

    Windows shows a blue “Windows protected your PC” box?

    That's normal for files from the internet. Click More info, then Run anyway.

  4. Make your password (first time only) A black window asks you to type a password for the dashboard. Use at least 10 characters, press Enter, and write it down somewhere safe. (On a Mac nothing appears while you type. That's normal.)
  5. The store opens in your web browser You'll see the shop. To get to your dashboard, go to http://localhost:3000/admin and sign in with your password.
Keep the black window open.

The black window is the store. While it's open, the store works. Closing it stops the store. To start again, just repeat step 3.

Students can't order yet

“localhost” means only this computer can see the store. That's perfect for trying it out. To let students order from their own phones, it has to be put online. See Part 3.

Part 2 — Using your dashboard

Go to /admin and sign in. Everything is done with buttons, with no code at all.

How an order moves along

New→In progress→Ready for pickup→Completed

Every time you change an order's status, the student can see it by clicking Track order on the store and typing their order number and email.

“I want to…”

I want to…Here's how
See new ordersClick Orders. New ones are marked NEW, and the menu shows how many are waiting.
Move an order alongClick the order, change Order status, click Save changes.
Mark an order as paidOpen the order, turn on the Paid switch, click Save changes.
Approve a special requestClick Requests. Type a price if it asks for one, then click Approve or Decline. You can add a message for the student.
Change a priceProducts & pricing, change the number, then click Save changes on the black bar at the bottom.
Stop selling something (for now)Products & pricing, turn off its For sale (or Shown) switch, then Save changes. Turn it back on any time.
Add a new designProducts & pricing → Designs → + Add design. Click Upload, pick the picture (a PNG works best), type a name, then Save changes.
Sell Christmas itemsProducts & pricing → Christmas collection. Turn on Show the collection, click + Add holiday item, add a photo, name and price, then Save changes.
Close the store (e.g. over break)Settings, turn off Store is open, then Save changes. Students see your “closed” message.
Put a message at the top of the storeSettings → Announcement banner. Type it and Save changes. Clear it to remove it.
Open orders in ExcelOrders → Export CSV. The file opens in Excel or Google Sheets.
Keep a backup copySettings → Download full backup. Keep the file somewhere safe.
Change my passwordSettings → Password. Or, if you forgot it, see Part 4.

What goes to “Requests”?

Anything that needs your OK before printing: an “Other” design or color, custom text (like a name or number), Bring Your Own Apparel, and Accessories / Others (those need you to type a price).

Part 3 — Putting it online so students can order

Hand this part to whoever helps with computers at school. It's a checklist. Technical details are in README.md.

  • Get the OK from the district. The store saves students' names, emails and phone numbers, so check the district's privacy rules first.
  • Pick a place to run it. It needs a computer or hosting service that is always on, runs Node.js 22 or newer, and keeps its files between restarts. Good choices: a school server, a small virtual server, or a host with a “persistent disk” (for example Render, Railway or Fly.io).
    ⚠️ “Static” hosting like GitHub Pages or Netlify will not work. It can't save orders.
  • Start it with node server.js in this folder (or npm start). It uses port 3000 unless you set PORT.
  • Set the owner password with node scripts/set-password.js "a long password", or start it the first time with ADMIN_PASSWORD set. Give the password only to Mr. Setzer.
  • Turn on HTTPS (the padlock in the address bar). Most hosts do this for you. Then set COOKIE_SECURE=1, and TRUST_PROXY=1 if the host sits in front of the app.
  • Back up the data folder. All orders live there. The store also keeps its own daily copy for 30 days in data/backups, but keep another copy somewhere else too.
  • Check it works: run npm test. It should end with “All checks passed”.
  • Share the address (for example https://store.yourschool.org) with students. The dashboard is that address plus /admin.

Part 4 — If something goes wrong

What you seeWhat to do
“Node.js is not installed”Do Part 1, step 1, then double-click Start OHS Store again.
The browser didn't open by itselfOpen any web browser and type http://localhost:3000.
“This site can't be reached”The black window was closed, so the store stopped. Double-click Start OHS Store again.
“something is already using port 3000”The store is already running in another black window. Use that one, or close it and start again.
I forgot my passwordClose the black window. Double-click Change Password (Mac: Change Password (Mac)), type a new one, then start the store again.
“Too many attempts”After 5 wrong passwords, sign-in locks for 15 minutes to keep the store safe. Wait, then try again.
Windows: “Windows protected your PC”Click More info, then Run anyway.
Mac: “can't be opened because it is from an unidentified developer”Right-click the file, choose Open, then Open again.
Orders are missingDon't panic. Look in the data/backups folder for daily copies, and ask your tech person to restore one (see README.md).
Good to know

Part 5 — Good to know

Never delete the data folder.

It holds every order, price and setting. To keep a copy, copy the whole folder somewhere safe (or use Settings → Download full backup).

What the store does not do (yet)

  • No online payments. Students pay in person, like before. Mark orders Paid in the dashboard.
  • No automatic emails. Students check their order with Track order. You can email a student straight from their order page.

Either one can be added later, but it needs an account with a payment or email company.

About the pictures

  • Designs: all 41 designs are real artwork. The two Sam Shield designs were rebuilt from screenshots and are a little less detailed. If you have the original files, upload them in Products & pricing → Designs (click Replace).
  • Shirts and hoodies: these are drawings, not photos. Christmas items can have real photos that you upload.
